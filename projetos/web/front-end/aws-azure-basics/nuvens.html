Produtos em Nuvem da Microsoft

Azure

O Azure é a plataforma de nuvem da Microsoft que oferece uma ampla gama de serviços, incluindo computação, armazenamento, banco de dados, redes e muito mais.

Microsoft 365

O Microsoft 365 é uma suíte de produtividade em nuvem que inclui aplicativos como Word, Excel, PowerPoint, Outlook e muito mais.

Power Platform

O Power Platform é uma plataforma de baixo código que permite que você crie aplicativos personalizados e automatize processos de negócios.
