## Como executar

Cada pasta é independente e pode exigir ferramentas e versões diferentes. Projetos PHP podem precisar de PHP e MySQL; os projetos Android devem ser abertos individualmente no Android Studio; páginas estáticas podem ser abertas em um navegador. Consulte os arquivos de cada projeto antes de executar.

## Curadoria

Foram mantidos os arquivos de código e recursos menores usados pelos projetos. Cópias idênticas, documentos, vídeos, instaladores, arquivos de build, caches de IDE e configurações locais ficaram fora do repositório. Os projetos antigos não foram reescritos: alguns são exercícios incompletos ou dependem de configuração adicional.

Credenciais locais não devem ser publicadas. Configure os dados de conexão somente no ambiente local.
